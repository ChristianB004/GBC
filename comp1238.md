## Week 5 - CLI
- Program writer prepared the program and input data on punch cards or tape
Operator ran it all
Results came back as paper printouts
- Interactive Terminals are the original command line.
Type a command, press Enter and the computer prints out response on paper.
- Initially the computer wasn’t even aware if it’s sending text to a paper printer, or monitor. VT100, released in 1978
- CLI loop: command – response (Like a chatbot or old text adventure games.)
-  CLI games like ZORG.
-  Here “>” is used as a “prompt”, it prompts you to input some command. Very limited set of commands at each step
-  SSH works remotely.
-  cp copies a file locally
cp myfile.txt some/other/dir/
scp can copy between computers
scp myfile.txt myserver.com:some/remote/dir/
- TMUX stands for Stands for “Terminal Multiplexer”. Split windows in the terminal & Keeps remote processes alive when you disconnect
